# IFE HUB — downloads

The Android app for **Ife Solutions Ltd** staff. Binaries only; the source is
not published here.

## Installing

Open [the latest release](../../releases/latest) on the phone, download the
`.apk`, and open it. Android asks once for permission to install apps from
this source.

Once the app is installed it looks after itself: it checks for a newer build
each time it opens and offers to install it.

## Who it is for

Staff of Ife Solutions Ltd, who sign in with the staff number and password
issued to them. Downloading the app gives no access to anything on its own.
